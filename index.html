The Four Paradigms Explained

fourcast contrasts four distinct eras of visual intelligence, all arriving at a single classification forecast:

1. Classical Computer Vision: Hand-Crafted Features

Before deep learning, features were engineered by domain experts. Dalal & Triggs (2005) introduced Histograms of Oriented Gradients (HOG) for pedestrian detection. Edge gradients are binned into orientation histograms over localized cells. A linear hyperplane (SVM) separates classes.

2. Deep Learning from Scratch: Learned Feature Hierarchies

Instead of hardcoding edge detectors, Convolutional Neural Networks (CNNs) learn filter kernels via backpropagation. Early layers capture edges and blobs; deeper layers synthesize animal ears, snouts, and fur textures.

3. Transfer Learning: Inductive Bias from Massive Data

Training from scratch on hundreds of images leads to overfitting. Transfer learning leverages models trained on millions of images (ImageNet), adapting only downstream task-specific linear heads.

4. Vision Foundation Models: Emergent Semantic Geometry

Modern Vision Transformers (ViT) trained via self-supervised objectives (such as DINOv2) learn representations where semantic concepts are naturally linearly separable in embedding space.
